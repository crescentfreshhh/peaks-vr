Embed

VR de-warp opens each file once and decodes keyframes in-process; Decode: auto/cuda uses the GPU (NVDEC) for the heavy 8K decode with a CPU fallback. The AI model always uses the GPU. Larger interval = fewer samples = faster. Timeout is the ceiling per scene before it's marked failed (0 = no limit); heavy 8K scenes may need several minutes.
